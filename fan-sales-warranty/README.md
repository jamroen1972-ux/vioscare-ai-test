# พัดลมดี — ระบบขาย ซ่อม สต๊อก และใบรับประกัน

ชุดไฟล์เว็บแบบติดตั้งเป็นแอปบนโทรศัพท์ได้ และซิงก์ข้อมูลกับ Supabase หลังเข้าสู่ระบบ GitHub

## ไฟล์ในชุดนี้

- `index.html` — เว็บแอป
- `manifest.webmanifest`, `sw.js`, `fan-icon-192.png`, `fan-icon-512.png` — การติดตั้งและใช้งานออฟไลน์
- `supabase.min.js` — Supabase JavaScript SDK ที่รวมไว้ในชุดไฟล์
- `supabase-schema.sql` — สำเนาโครงสร้างตารางและนโยบายความปลอดภัย
- ไฟล์ `fan-hero-banner*.png` — ภาพหน้าร้าน

## การจัดเก็บข้อมูล

เว็บเก็บสำเนาในเครื่อง และซิงก์เอกสารข้อมูลของบัญชีที่เข้าสู่ระบบไปยังตาราง `public.fan_shop_data` ใน Supabase โครงการ Vios Care ข้อมูลในตารางแยกตามบัญชีผู้ใช้และป้องกันด้วย Row Level Security (RLS) โดยต้องเข้าสู่ระบบ GitHub ก่อนซิงก์

โปรเจกต์นี้ตั้งค่าตารางและ RLS ไว้แล้ว ไฟล์ SQL แนบไว้เพื่อสำรองหรือสร้างตารางใหม่ภายหลัง อย่าปิด RLS และอย่าใส่ `service_role` key ลงในไฟล์หน้าเว็บ

## ติดตั้งบน Android

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปไว้ในโฟลเดอร์ `fan-sales-warranty` บน GitHub Pages ให้ไฟล์ `index.html`, `manifest.webmanifest`, `sw.js` และไอคอนอยู่ระดับเดียวกัน
2. เปิดเว็บไซต์ที่เผยแพร่แล้วด้วย Chrome และรอให้หน้าเว็บโหลดครบ โดยต้องเป็น HTTPS
3. แตะปุ่มติดตั้งในหน้าเว็บ หรือเปิดเมนู Chrome `⋮` แล้วเลือก “ติดตั้งแอป”
4. เปิดแอป แล้วแตะปุ่มรูปเมฆเพื่อลงชื่อเข้าใช้ GitHub และเริ่มซิงก์

หากระบบแจ้งว่า URL กลับจาก GitHub ไม่ได้รับอนุญาต ให้เพิ่ม URL ของเว็บไซต์ที่เผยแพร่ลงในรายการ Redirect URLs ของ Supabase Auth ก่อนเข้าสู่ระบบอีกครั้ง

## ข้อมูลตัวอย่าง

รายการขายตัวอย่างรหัส `F-1028` ถึง `F-1025` และงานซ่อมตัวอย่างรหัส `R-0206` ถึง `R-0204` จะถูกลบเมื่อเปิดเว็บ ข้อมูลอื่นที่บันทึกไว้และโปรไฟล์ร้านจะคงอยู่ ส่วนการติดตั้งใหม่ที่ยังไม่มีข้อมูลจะเริ่มด้วยรายการขาย งานซ่อม สต๊อก และประกาศว่าง พร้อมให้กรอกข้อมูลจริง
